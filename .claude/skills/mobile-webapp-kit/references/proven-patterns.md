# 검증된 화면·서버 패턴 (올포오션 2026-11 최종본)

올포오션(해양사업본부 PWA)을 수십 번 고치며 사용자가 최종으로 고른 모양과, 실제로 터졌던 문제의 해법이다.
**모든 웹앱에 기본으로 적용**하고, 해당 기능을 만들 때는 `assets/snippets/`의 코드를 그대로 가져다 쓴다(이름만 맞춤).

## 0. 작업 방식 (매번)

- 디자인이 바뀌면 시안 3개를 **한 파일 안에 플래그로** 만든다(`S.xxxV = 'A'|'B'|'C'`, 기본값은 예전 모양). Playwright로 `#demo`를 열어 세 안을 한 장으로 붙여 보여 준다.
  고르기 전에는 `main`에 올리지 않는다. 커밋해야 하면 별도 브랜치(`*-mockup`)에 올린다. 고르면 나머지 안의 코드·CSS를 지우고 배포한다.
- 사용자가 결과를 보고 싶어 하므로 **바뀐 화면은 매번 스크린샷으로 오른쪽 패널에 띄운다**(SendUserFile, display=render). 밝은·어두운 화면을 나란히.
- 배포 전 확인: `node --check`(JS 조각), Apps Script는 `node -e "new Function(src)"`로 문법 검사. **한 줄짜리 코드 중간에 `// 주석`을 넣으면 뒤 코드가 주석이 된다**(두 번 터짐) → 주석은 줄 위에 따로.
- Apps Script는 **같은 이름의 함수가 두 개면 뒤의 것이 앞의 것을 조용히 덮는다**(새 도우미 `safe_`가 기존 `safe_`를 덮어 시트 쓰기가 전부 깨졌음). 새 함수를 만들기 전에 `grep -n "^function 이름"`, 배포 전 `eslint --rule no-redeclare`·`no-undef`로 검사한다.
- 서버에서 **목록의 한 줄마다 시트를 다시 읽지 않는다**(`rows_()`를 공고마다 부르면 600줄 × 시트 읽기 → 불러오기 수십 초 → 앱 '연결 안 됨'). 요청 시작에 한 번 읽어 객체로 들고 다닌다. 행이 크게 늘어나는 작업(지난 자료 채우기 등) 뒤에는 불러오기 시간을 다시 잰다.
- 불러오기(`load`)는 부분마다 `try`로 감싸 한 곳(캘린더·외부 API)이 실패해도 나머지는 보이게 하고, 실패한 부분 이름을 돌려준다. 앱의 fetch에는 시간 제한(60초)을 두고, 연결 실패·HTTP 오류·시간 초과를 다른 문구로 보여 준다.
- 배포 때마다 `bump_version.py`. 서버(Code.gs)를 바꿨으면 "새 버전으로 배포"를 꼭 안내하고, 앱만으로 해결되는 부분과 서버 배포가 필요한 부분을 나눠 말한다.
- 자료가 이상하면 추측하지 말고 **실제 자료를 먼저 본다**(구글 시트 값, API 직접 호출, 캘린더 원문). "없어서 없는지, 못 받아서 없는지"를 숫자로 답한다.

## 1. 글·정렬·숫자

- 설명 글은 가운데 정렬 + `word-break:keep-all; overflow-wrap:break-word; text-wrap:balance` (낱말이 잘리지 않게). 긴 안내문·스위치 옆 설명은 왼쪽.
- 비율로 오는 값(0.9711)은 화면에서 `%`로(`bidPct`: 1.5 이하면 ×100, 소수 둘째 자리). 서버 저장도 % 문자열로 맞춘다.
- 빨간 숫자 배지는 **0이면 아예 그리지 않는다**(빈 배지가 붉은 선처럼 보였음). 거르기 칩도 0건이면 숨기되, '전체'와 지금 고른 칩은 남긴다.
- 한글 입력칸이 있는 화면은 글자마다 전체를 다시 그리지 않는다(조합 중인 글자가 깨짐). 목록 부분만 다시 그린다.

## 2. 색감 (사용자 선택: 파스텔 '하늘' A안)

- `<html data-pal="A">` + 토큰: 맨 위 띠 `--top-bg:#d6e9f7`/글자 `--top-ink:#1f4d70`, 강조 `#4f93c9`, 바탕 `#f3f8fc`, 칩 `#e9f2fa`. 어두운 화면은 같은 계열을 낮춘 값.
- **어두운 화면에서 강조색이 밝은 파스텔이면 그 위 글자는 흰색이 아니라 짙은 남색(#0d2436)**. 버튼·선택 칩·재생 버튼·오늘 날짜 원 모두.
- 상태색은 파스텔 바탕 + 진한 글자 짝(`--p-go/-ink`, `--p-warn`, `--p-stop`, `--p-blue`, `--p-violet`). 지도 핀·적합/유의/불가 막대는 구분이 중요하므로 진한 색 유지.

## 3. 카드 모양 (사용자가 고른 안)

- **목록 카드**: 흰 카드 목록(`.bcl`) 안에 꼬리표 줄(종류·NEW·D-day·별) → 파란 제목 → 기관 → 회색 정보 칸(3칸 격자). 모든 카드가 같은 칸에 같은 정보.
- **아직 안 나온 것(예정·예상)**: 같은 카드 틀에 점선 꼬리표 '공고 예정' + D-day 자리에 보라 'N월 예상', 제목은 검은 글씨(이미 나온 것은 파랑).
- **종류가 섞인 목록**은 묶음 제목(색 막대 + 이름 + 건수)으로 나눈다. 순서는 사용자가 정한 대로.
- **수치 두 개가 붙는 카드**(파고·풍속 등): 숫자마다 이름표·아이콘이 달린 작은 칸에 따로 넣는다("0m 2.9m/s"처럼 붙이면 구분이 안 됨). 상태는 맨 위 한 줄, 그 아래 굵은 이름.
- **보고서형 상세**(C안): 그라데이션 머리띠(팀·이름·D-day + 원형 진행률) → 사실 표 → 이슈 빨간 칸 → 문단별 왼쪽 색 선. 문단 선 색은 서로 다르게(실적 파랑·계획 초록·일정 보라) 하고 제목 글자·목록 점도 같은 색.
- **주 버튼 + 보조 버튼 한 줄**: 주 동작은 강조색 꽉 찬 버튼, 보조는 흰 버튼에 아이콘 + 두 줄 글(예: "날씨 새로 받기 / 1시간 전 받음"), 진행 중엔 아이콘 회전.

## 4. 지도 (`assets/snippets/map-adapter.js`)

- 카카오맵 JavaScript 키만 쓴다(REST·어드민 키 금지). CSP에 `dapi.kakao.com *.daumcdn.net *.kakaocdn.net`, referrer는 strict-origin. 실패하면 Leaflet+OSM으로 자동 전환하고 토스트로 알린다.
- 범위 맞춤: 고른 점이 모두 보이게 **사방 같은 여백 → 한 단계 더 축소 → 중심점 가운데**. 점이 없으면 우리나라 전체. 예전에 본 범위를 다시 쓰지 않는다(손가락이 지도를 지나가며 스크롤한 것도 '만짐'으로 잡혀 엉뚱한 곳이 열렸음).
- 지도 위에서는 탭 넘김 스와이프를 막는다(`data-noswipe`). 오른쪽에 있는 핀은 이름표를 왼쪽에.
- 핀을 누르면 **지도 위 말풍선**(어두운 상자, 이름 굵게·장소·회색 설명·파란 지역)을 띄우고 지도를 그 핀으로 옮긴다. 같은 핀을 다시 누르면 닫힘.
- 주소 → 좌표는 서버에서 Apps Script `Maps.newGeocoder()`(키 없음). 통째로 → 앞 단어부터 줄여 가며 → 괄호 안 지명 순으로 찾고, 결과는 스크립트 속성에 기억. 우리나라 범위 밖 결과는 버린다.

## 5. 시간·그래프 (`assets/snippets/charts.js`)

- 가로축은 **실제 시각 비례**(예보 끝부분은 3시간 간격이라 칸 수로 나누면 휘어 보임). 날짜 글자는 그날 구간 가운데에, 좁은 첫날·끝날은 생략(겹침·잘림 방지).
- 시간 막대는 iOS `input[type=range]` 대신 div로 만든 막대(페이지가 같이 스크롤되고 말풍선이 어긋났음). 하나의 막대, 끝에서 멈춤, ×1/×2/×4.
- 그래프를 누르거나 끌면 그 시각 값과 판단을 아래에 보여 준다.
- **물때 곡선**: API가 만조·간조 시각·높이만 주면 그 사이를 코사인으로 잇는다. 오늘·내일 이틀치를 받아 자정 앞뒤가 이어지게. 지금 시각 점선·점, "들물 ↗/날물 ↘", 설명은 가운데 두 줄.

## 6. 달력·표

- **글 속 날짜 → 달력** (`assets/snippets/text-calendar.js`): `11/09~13`, `11.24`, `11월 11일`, `12/2~4`, `11/9, 11/12`, `(~11.18)`, `2026.11.13`을 읽고, `91.6%`·`v3.0`·`109/109`와 보고서 작성일은 버린다. 종류별 점 색, 기간은 띠, 날짜를 누르면 그날 목록만.
- **사람 × 평일 표** (`assets/snippets/week-grid.js`): 휴가 초록 칸, 출장 파란 칸, 반차는 칸 절반, 시간 반차는 그 시간 위치에 막대. 이번 주/다음 주(주말엔 '다가오는 주'), 날짜 누르면 그날만, 칸 누르면 그 칸 아래 말풍선(이름·팀·직급·날짜, 출장은 장소·목적·지역, 휴가는 사유). 출장지 지도도 같은 날짜 필터.

## 7. 로그인·관리자

- 비밀번호 6자리를 채우면 자동 로그인: `input`만 보지 말고 `keyup`·`change`·`paste`도(아이폰 자동 채우기). 보내는 동안 버튼 글자 "확인하고 있어요…", 키보드 내리기, 같은 값 두 번 보내지 않기.
- 종 아이콘 숫자 = 새 소식 + (관리자면) 가입 승인 대기 + 새 건의. 종을 누르면 맨 위에 '관리자 할 일'(그 자리에서 승인·거절, 건의함 바로가기).
- 초대: 관리자만 보이는 '초대 링크 보내기'(공유 창)·'초대 문구 복사'. 링크는 `?join` → 처음 연 사람에게 가입 탭. **자동 새 버전 새로고침(`?v=`)이 `?join`을 지우지 않게** 붙여서 넘긴다.
- 개인 정보 원칙은 처음 정한 대로 지키되, 사용자가 명시적으로 바꾸면(예: 출장 장소·사유 표시) 그대로 따르고 바뀐 점을 한 줄로 알린다.

## 8. 공공데이터·외부 자료 (서버, `assets/snippets/apps-script-data.gs`)

- 인증 오류는 JSON이어도 `OpenAPI_ServiceResponse.cmmMsgHeader`로 온다 → 이것을 오류로 잡지 않으면 **"자료 0건"으로 조용히 넘어간다**. 새 API는 JSON에 `response` 껍데기가 없을 수 있다(`(j.response || j).body`).
- 새 공공데이터 API는 **활용신청을 따로** 해야 한다(같은 인증키라도). 안내할 때 데이터 번호와 링크를 같이.
- 기상청 단기예보 파고(WAV)는 **육지 격자에서 빈 값이 아니라 0**을 준다 → 3일 내내 0이면 육지로 보고 가까운 바다 격자(반경 ~30km)에서 가져오고, 찾은 격자를 기억. 못 찾으면 0 대신 '자료 없음' + "지점을 바다 쪽으로 옮겨 주세요". 파고는 0.5m 단위라 잔잔하면 일직선이 정상.
- 국립해양조사원 조석예보는 `apis.data.go.kr/1192136/tideFcstHghLw/GetTideFcstHghLwApiService`(데이터 15156018, `obsCode`=DT_xxxx, `reqDate`, `type=json`, `extrSe` 1·3 고조 / 2·4 저조, `predcTdlvVl` cm). 옛 khoa.go.kr 주소는 폐지.
- API 명세는 data.go.kr 상세 페이지 HTML 안 `swaggerJson`에 들어 있고, 활용가이드(hwpx)는 zip이라 `Contents/section*.xml`의 `<hp:t>`를 읽으면 코드표가 나온다.
- 공고가 나라장터에 없는 기관(예: KIMST)은 기관 게시판 표를 서버에서 긁는다(`?page=N`). 해마다 다시 나온 사업만 '예상'에 넣고, 달별 막대로 언제 몰리는지 보여 준다.
- 서버 캐시 키는 자료 모양을 바꿀 때마다 올린다(`absence3` → `absence4`), 캐시 시간은 짧게(3분) — 방금 올라온 일정이 안 보인다는 문의가 나온다.
- 육상 공고처럼 '관련 없는 것이 많이 나온다'는 말이 나오면 실제 제목 목록으로 거르기 규칙을 돌려 보고 결과(남은 건수)를 보여 준다. 불러올 때도 같은 규칙으로 한 번 더 거른다.
