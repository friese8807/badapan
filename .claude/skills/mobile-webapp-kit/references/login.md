# 로그인·사람 구분·접속 기록

가족용 앱(윤호채원이네, 힐스초등수학)의 공통 방식.

## 로그인

- **처음 한 번만** 넣으면 그 휴대폰에 기억한다(`LS.set('auth', …)`). 로그인 화면에 "처음 한 번만 넣으면 이 휴대폰에 기억됩니다"라고 적는다.
- 사람을 고르는 버튼(아빠·엄마·아이 이름) + 숫자 비밀번호(4~8자리). 입력칸은 `type="password" inputmode="numeric"`, 글자 16px 이상.
- 비밀번호 확인은 **서버에서** 한다. 화면 코드(공개 저장소)에 비밀번호를 넣지 않는다. 모든 요청에 `auth`를 함께 보내고 서버가 매번 확인한다.
- 틀리면 입력칸을 비우고 다시 초점, 이유를 칸 아래에 보여 준다.
- 비밀번호가 바뀌어 거절되면 자동으로 로그아웃하고 "다시 로그인해 주세요".
- 비밀번호 없이도 쓸 수 있게 시작하고, 설정 탭에서 정하도록 안내하는 방식이 가족용에는 편하다.

## 사람·권한

- 부모/아이처럼 역할이 다르면 서버가 역할별로 할 수 있는 일을 확인한다(화면에서 버튼만 숨기는 것으로 끝내지 않는다).
- "잠깐 아이에게 넘겨주기": 부모 폰에서 아이 모드로 바꾸고, 돌아올 때 부모 비밀번호를 묻는다.
- 권한은 설정의 스위치로 부모가 바꿀 수 있게(예: 벌점은 아빠만, 스위치를 켜면 엄마도).
- 기기 이름("아빠 폰", "엄마 폰")을 로그인 때 고르게 하면 기록에서 누가 했는지 알 수 있다.

## 홈 화면 앱에서 로그인이 풀릴 때

- 사파리와 홈 화면 앱은 저장소가 따로다. 사파리에서 로그인해도 홈 화면 앱에서는 다시 해야 한다고 알린다.
- 앱을 다른 사이트 안(`iframe`)에 넣으면 아이폰이 앱을 닫을 때 저장소를 지운다. 그래서 앱 화면은 `github.io`에서 직접 내보낸다.
- 설정값이 길면 한 번 누르는 설정 링크(`#setup=`, `references/apps-script.md`)를 쓴다.

## 접속 기록

- 서버 호출에 `meta: AppKit.device()`(기기 종류·iOS 버전, 브라우저/홈화면 앱/위젯)를 함께 보내고, 서버가 "접속" 시트에 누가·언제·어떻게를 적는다.
- 설정 탭에 부모만 보는 "최근 접속" 목록을 둔다. 접속 기록 호출은 진행 표시를 띄우지 않는다(`AppKit.wrap`의 `skip`).
