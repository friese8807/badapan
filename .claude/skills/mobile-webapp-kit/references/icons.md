# 홈 화면 아이콘

## 디자인 (지금까지 만든 아이콘의 공통점)

- 정사각형 512 기준 SVG로 그린다. **배경을 끝까지 채운다** — 둥근 모서리는 아이폰·안드로이드가 깎는다. 직접 둥글게 그리면 검은 귀퉁이가 생긴다.
- 그림 하나만 크게: 발자취=발자국, 수급 레이더=막대 그래프, 힐스수학=칠판과 연산 기호. 가운데 60~70% 안에 둔다(maskable은 바깥 10%가 잘린다).
- **글자는 넣지 않는다.** 작게 보이면 읽히지 않고, 서버에 한글 글꼴이 없으면 네모로 그려진다. (힐스수학의 "힐스" 글자가 이 경우.)
- 배경은 앱의 대표 색 그라데이션 또는 어두운 단색, 그림은 흰색이나 2~3색. 앱 화면의 `--accent`와 맞춘다.
- 사진을 쓸 때(윤호채원이네의 강아지): 얼굴이 가운데 오도록 정사각형으로 자르고 512px 이상 원본을 쓴다.
- 만들고 나면 512 PNG를 직접 열어 보고, 180 크기에서도 알아볼 수 있는지 확인한다.

## 파일

`python3 scripts/make_icons.py icon.svg 앱폴더 --v 1` 이 아래 네 개를 만든다.

| 파일 | 쓰임 |
|---|---|
| `icon-180-v1.png` | 아이폰 `apple-touch-icon` |
| `icon-192-v1.png` | 안드로이드, 파비콘 |
| `icon-512-v1.png` | 안드로이드, 시작 화면 |
| `icon-512-maskable-v1.png` | 안드로이드 적응형 (그림을 80%로 줄여 배경 위에) |

```html
<link rel="apple-touch-icon" sizes="180x180" href="icon-180-v1.png">
<link rel="icon" type="image/png" sizes="192x192" href="icon-192-v1.png">
<link rel="manifest" href="manifest.webmanifest?v=1">
```

## 하지 말 것 (실제로 겪은 문제)

- `apple-touch-icon`에 **SVG·JPG를 쓰지 않는다.** 일부 아이폰이 무시하고 화면 캡처를 아이콘으로 쓴다. 반드시 PNG.
- **투명 배경 금지.** 아이폰은 투명을 검게 칠한다. (`make_icons.py`가 자동으로 채운다.)
- 아이콘을 바꿀 때 **같은 파일 이름을 덮어쓰지 않는다.** 아이폰이 예전 아이콘을 붙잡는다. `--v 2`로 새 이름을 만들고
  `index.html`·`manifest`·`sw.js`의 파일 이름과 `manifest.webmanifest?v=2`를 함께 바꾼다.
- 바꾼 뒤에는 사용자가 홈 화면에서 앱을 지우고 다시 추가해야 한다고 알린다.
- 그래도 아이콘이 안 나오는 아이폰은 웹 클립 프로필(`.mobileconfig`, 윤호채원이네 `ycn.mobileconfig` 참고)이 마지막 수단이다.
