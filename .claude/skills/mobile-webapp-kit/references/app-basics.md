# 앱 기본 구조·데이터·오류

네 앱이 모두 같은 틀을 쓴다. 새 앱도 이 틀로 시작한다.

## 구조

- **파일 하나** `index.html`(CSS·JS 포함), 빌드 도구·프레임워크 없음. GitHub에서 바로 고칠 수 있어야 한다.
- 상태는 `const S = {...}` 한 곳. 화면은 `render()`가 `S`를 보고 `innerHTML`로 다시 그린다.
- 버튼은 `data-*` 속성 + `document`에 건 클릭 한 개로 처리한다(다시 그려도 연결이 끊기지 않는다).
- 서버·사용자 글자를 넣을 때는 반드시 `AppKit.esc()`.
- 저장은 `const LS = AppKit.store('앱접두어')`. 같은 `github.io` 주소를 여러 앱이 함께 쓰므로 접두어가 꼭 필요하다.
- 마지막으로 본 탭·선택(아이, 종목, 단위)은 저장해 두고 다음에 그대로 연다.

## 데이터 갱신

1. **먼저 보여 주고 뒤에서 갱신** — 저장해 둔 지난 데이터로 바로 그리고, 새로 받아 바꾼다.
2. **자동 새로고침** — `AppKit.poll(refresh, 30000, () => sheet.isOpen)`. 화면이 안 보이면 멈추고, 돌아오면 바로 한 번. 간격을 함수로 주면 상황에 따라 바꾼다(수급 레이더: 장중 15초, 마감 뒤 2분).
3. **입력값 보호** — 배경 새로고침은 `AppKit.editing()`이 참이거나 시트가 열려 있으면 다시 그리지 않는다.
4. **늦은 응답 버리기** — 달·날짜를 빠르게 넘기면 예전 응답이 나중에 온다. `const seq = AppKit.sequence()` → `const mine = seq.next(); …await…; if(!seq.is(mine)) return;`
5. **오프라인 대기열** — 실패한 기록은 `LS`에 쌓았다가 `online` 이벤트와 시작할 때 다시 보낸다. "연결되면 자동 전송할게요"라고 알린다.
6. **갱신 상태 표시** — 머리글에 `<span class="ak-status"><i class="ak-dot live"></i>14:32 갱신</span>`. 실패하면 `off` + 마지막 성공 시각.
7. **날짜** — 휴대폰 시간대와 상관없이 한국 시간(`AppKit.kstDate()`). "오늘"은 서버가 알려 주는 값을 우선한다.

## 오류·실수 방지

- `AppKit.showErrors(BUILD)` — 앱 오류를 화면 위에 줄 번호와 함께 보여 준다. 사용자가 캡처해 주면 바로 고칠 수 있다. `Script error.`는 무시.
- 서버 오류는 쉬운 말 토스트로: "서버에 연결하지 못했어요. 잠시 후 다시 해주세요."
- 첫 불러오기 실패는 `.ak-empty` + "다시 시도" 버튼.
- **두 번 눌림 방지** — 누르면 바로 `disabled`(또는 `AppKit.wrap`의 `.is-busy`). 서버도 같은 요청이 두 번 와도 한 번만 기록하게 한다.
- **지우기** — `if(!AppKit.sure(btn)) return;` 로 두 번 눌러야 지워지게. 돈·잠금처럼 큰 동작은 `confirm()`에 금액·대상을 적는다.
- 끝나면 결과를 토스트로 알린다("저장했어요", "삭제했어요. 지난 기록은 남아요").
- 로그인이 풀렸다는 응답(`code:"auth"`)이면 로그인 화면으로 보내고 이유를 알린다.

## 예시(데모) 모드

- 서버 주소가 없거나 `#demo`로 열면 **예시 데이터**로 화면 전체가 동작한다. 설정 전에도 앱을 구경할 수 있고, 화면 확인(Playwright)에도 쓴다.
- 예시일 때는 `.ak-demo` 띠로 "예시 데이터입니다"를 분명히 표시한다. 예시 좌표·값은 그럴듯한 실제 값으로.

## 글·숫자·모양

- 문구는 쉬운 우리말, "~요"체. 개발 용어·영어 오류 문구를 그대로 보여 주지 않는다. 코드 주석도 한글로 "왜"를 적는다.
- 숫자는 `AppKit.num/krw/signed`(ko-KR, 음수는 `−`), 큰 금액은 억·조. 숫자 칸에는 `.num`(자릿수 고정).
- 주식·증감 색: **오른 것·산 것 빨강, 내린 것·판 것 파랑**(한국 관례).
- 아이콘은 줄 아이콘 SVG(`.ak-ic`, `stroke="currentColor"`)를 `index.html`에 직접 넣는다. 아이콘 글꼴·외부 그림을 쓰지 않는다. 이모지는 탭바·장소처럼 가벼운 곳에만.
- 글꼴은 시스템 글꼴 우선. 웹 글꼴(Pretendard, Jua 등)은 제목에만, `preconnect`와 함께.
- **설명 글은 가운데 정렬**한다(화면 아래 안내, 지도·그래프 설명, 범례, 빈 화면 문구). 여러 문단·목록으로 된 긴 안내(개인정보, 설치 방법)와 스위치 옆 짧은 설명은 왼쪽 정렬로 둔다.
- **줄이 바뀔 때 낱말이 잘리지 않게** 한다. 한글은 기본값이면 글자 단위로 끊겨 "바\n뀌어요", "마\n지막"처럼 된다. 가운데 정렬 글에는 아래 세 줄을 같이 넣는다(`app-kit.css`의 `.ak-center`·`.note` 등에 들어 있음).
  `word-break:keep-all`(낱말 단위로만 줄바꿈) · `overflow-wrap:break-word`(칸보다 긴 주소·코드만 그 안에서 끊기) · `text-wrap:balance`(줄 길이를 고르게 맞춰 마지막 줄에 한두 글자만 남지 않게).
  글자를 줄이거나 `<br>`을 손으로 넣어 맞추지 않는다(화면 폭마다 달라진다). 배포 전 390px 폭 화면 사진으로 끊긴 낱말이 없는지 본다.
- 누를 수 있는 것은 44px 이상. 그림만 있는 버튼에는 `aria-label`. 토스트는 `role="status"`.
- 가족·개인용 앱은 `<meta name="robots" content="noindex, nofollow">`.
