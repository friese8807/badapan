# 그 밖에 되풀이한 작업

## 서버 없이 자료를 주기적으로 받기 (수급 레이더)

- GitHub Actions가 자료를 받아 **`data` 브랜치**의 `data.json`에 올리고, 앱·위젯은 그 파일을 읽는다. 사용자가 서버를 따로 만들 필요가 없다.
- 읽는 주소: `raw.githubusercontent.com/계정/저장소/data/data.json`(약 5분 캐시). 더 빨리 필요하면 GitHub API `contents/data.json?ref=data`를 먼저 쓰고(시간당 60회 제한) 실패하면 raw로.
- 예약 실행은 늦거나 빠진다. 시작 시각을 여러 번 걸고, `concurrency`로 겹치지 않게 하고, 한 번 시작하면 끝날 때까지 반복(`sleep`)하는 방식이 가장 고르게 돌았다.
- `data` 브랜치는 매번 새로 만들어 강제로 올린다(기록이 쌓이지 않게). `permissions: contents: write`.
- 더 자주·더 많은 자료가 필요하면 선택 사항으로 Apps Script 주소를 설정에 넣을 수 있게 한다.

## 사진

- 올리기 전에 `AppKit.toJpeg(file, 1100)`으로 줄인다. 프로필은 정사각형 320.
- 인증 사진에는 날짜·이름을 사진 아래에 찍어 두면 나중에 확인하기 좋다(윤호채원이네 `toJpeg`의 `stamp`).
- 같은 사진을 다시 올리는지 보려면 파일 해시(SHA-256 앞 16바이트)를 함께 보낸다.
- 드라이브 사진은 서버가 data URL로 돌려주고 화면이 기억해 둔다(다시 받지 않게).
- `<input type="file" accept="image/*" capture="environment">`로 카메라를 바로 연다.

## 다른 앱으로 넘기기

- 토스 송금: `supertoss://send?bank=은행&accountNo=숫자만&amount=금액`. 계좌는 설정에 저장.
- 복사: `AppKit.copy(text)` — 실패하면 글자를 토스트로 보여 준다.
- 진동: `AppKit.buzz()` — 기록 완료, 길게 누르기 인식 때 짧게(아이폰은 지원하지 않으므로 없어도 되는 곳에만).
- 주소에 값 넣어 열기: `?date=2026-11-12`, `?via=widget` 처럼 위젯·알림에서 특정 화면으로 바로 연다.

## 지도 (발자취)

- 카카오맵(키가 있고 등록한 주소에서 열 때) → 실패하면 Leaflet. 두 지도를 같은 함수 모음(어댑터)으로 감싼다.
- 지도 위 고정 요소·시트가 지도 로고를 가리지 않게 지도 아래 끝을 시트 위로 맞춘다.
- 지도 안에서는 좌우 스와이프를 쓰지 않는다(`AppKit.swipe`가 `.leaflet-container`를 무시한다. 카카오 지도에는 `data-noswipe`).

## 저장소 작업 방식

- 화면만 고치는 작은 변경은 `main`에 바로. 기능 단위 변경은 `claude/…` 브랜치로 올린다(끌어오기 요청은 사용자가 원할 때만).
- 커밋 글은 무엇이 달라졌는지 사용자 눈으로 본 한 줄("탭바가 스크롤해도 움직이지 않게").
- 저장소가 공개이므로 비밀번호·개인 키를 넣지 않는다. 화면에 꼭 필요한 공개용 키(카카오 JavaScript 키)는 등록한 주소에서만 동작하게 제한한다.
