# 바다판

올포랜드·엘티메트릭 해양사업본부 공용 휴대폰 웹앱이에요. 입찰 레이더, 현장 날씨판, 사업 일정, 오늘판을 한 앱에 담았어요.
승인된 구성원만 쓸 수 있어요. 주소 뒤에 `#demo`를 붙이면 서버 없이 예시 데이터로 열려요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체(화면·동작). 업무 자료와 비밀값은 들어 있지 않아요 |
| `Code.gs` | Apps Script 서버: 로그인·권한 확인·시트 저장·공공데이터 수집·아침 메일 |
| `manifest.webmanifest`, `sw.js`, `version.txt`, `icon-*-v1.png` | 홈 화면 앱 설정, 오프라인, 새 버전 알림, 아이콘 |

## 처음 연결하기 (본부 공용 구글 계정으로)

1. script.google.com → 새 프로젝트 → `Code.gs` 붙여 넣기 → `setup` 실행(권한 허용). 실행 로그에 나온 시트는 공유하지 않아요.
2. `createAdmin('이름', '올포랜드', '해양SI 1팀', '숫자6자리')` 를 한 번 실행해 첫 관리자를 만들고, 그 줄의 숫자는 지워요.
3. 프로젝트 설정 → 스크립트 속성: `DATA_GO_KR_KEY`(공공데이터포털 인증키), 필요하면 `ABSENCE_CALENDAR_ID`(본부 휴가·출장 캘린더 ID).
   공공데이터 주소가 바뀌었으면 `EP_BID`, `EP_PRE`, `EP_FCST`, `EP_WRN`, `EP_TIDE` 로 바꿔 넣어요.
4. 배포 → 새 배포 → 웹 앱 (실행: 나, 액세스: 모든 사용자) → 나온 `…/exec` 주소를 `index.html`의 `API_URL`에 넣어요.
5. `installTriggers` 실행 → 공고 수집(매시), 날씨(3시간), 아침 메일(8시), 정리(새벽 4시).

공공데이터포털에서 활용 신청할 서비스: 조달청 나라장터 입찰공고정보서비스, 나라장터 사전규격정보서비스, 기상청 단기예보 조회서비스, 기상청 기상특보 조회서비스. 물때는 국립해양조사원 바다누리 조석 예보(지점 시트의 `obsCode`에 관측소 코드, 예: 목포 DT_0007).

## 보안 요약

- 비밀번호는 서버에 사람별 소금값과 서버 비밀값으로 암호화한 값만 남아요. 휴대폰에는 로그인 표(토큰)만, 시트에는 토큰의 암호화 값만 남아요.
- 5번 틀리면 15분 잠금, 로그인은 30일, 기기별 로그아웃, 비밀번호를 바꾸면 다른 기기 로그아웃.
- 역할(팀원·팀장·본부장·관리자)은 서버에서 확인해요. 접속 기록·메일 주소는 관리자만 봐요.
- 저장하는 개인정보: 이름, 회사, 팀, (선택) 메일, 기기 종류, 접속 시각. 접속 기록은 180일 뒤 자동 삭제.

## 고칠 때

- 화면을 고치면 `bump_version.py`로 `version.txt`를 올려요. 휴대폰에서 다시 열면 새 버전이 떠요.
- 서버를 고치면 배포 관리 → 수정 → 새 버전으로 다시 배포해요(주소는 그대로).
